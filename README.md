# UK-Regional-Performance-Dashboard
An organisation needed a way to monitor operational performance and track key performance indicators (KPIs) across 12 regional teams. The goal was to identify underperforming regions, track target outcomes and understand pipeline drop-offs.
Tools used: Power BI Desktop, DAX, Power Query
Key Insight #1: Region B had the highest start conversion efficiency, despite having the fifth smallest amount of engagements.  
Key Insight #2: Region C has the highest percentage of achieved outcomes vs. target outcomes (67%)/
